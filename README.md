# StudyMind — منصة الاستذكار والتعلم التفاعلي الذكي
> **StudyMind — AI-Powered Interactive Learning Platform & Standalone Android APK**

تطبيق دراسي تفاعلي متكامل قائم على أحدث تقنيات الذكاء الاصطناعي من Google Gemini، يتيح للطلاب والمعلمين رفع الكتب والمذكرات الدراسية (PDF، DOCX، TXT) وتحويلها إلى مساحة تعلم تفاعلية تشمل: المحادثة المعرفية الموثقة بالمصادر، الملخصات الشاملة، بطاقات الاستذكار السريع، الامتحانات التفاعلية، ورسوم المخططات التوضيحية مع إمكانية استفسار وسؤال الطالب عن أي شكل ومخطط لفهمه بشكل معمق.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **📱 تطبيق أندرويد مستقل يعمل بدون إنترنت ومع الإنترنت (Offline & Online Standalone APK)**:
   - حزمة الويب البرمجية مدمجة بالكامل داخل ملف الـ APK عبر `WebViewAssetLoader`.
   - عند فتح التطبيق على الهاتف، يفتح مباشرة من الذاكرة الداخلية للهاتف دون الحاجة لأي خادم خارجي ودون ظهور رسائل "تعذر تحميل صفحة الويب".
   - **العمل في وضع عدم الاتصال (Offline)**: جميع المستندات التي رفعتها، بطاقات الاستذكار، الاختبارات، الملخصات، والمخططات تبقى محفوظة بشكل دائم وتستطيع مراجعتها واختبار نفسك بها في أي وقت حتى عند انقطاع الإنترنت بالكامل.
   - **العمل عند الاتصال (Online)**: عند توفر الإنترنت، تتاح لك قدرات الذكاء الاصطناعي التوليدية المتقدمة.

2. **📚 معالجة المستندات الكبيرة وفهرستها بدقة**:
   - قراءة واستخراج نصوص ملفات PDF و DOCX وحساب عدد الصفحات الفعلي بدقة كاملة.

3. **💬 محادثة معرفية موثقة (Grounded RAG Chat)**:
   - إجابات دقيقة مستندة حصراً إلى نصوص المستند مع توثيق أرقام الصفحات الحقيقية.

4. **📝 ملخصات مفاهيمية عميقة (In-Depth Summaries)**:
   - تلخيص شامل، تنفيذي، أو سريع للفصول، مع استخراج القواعد والمفاهيم والنقاط الحرجة للاختبارات.

5. **🗂️ بطاقات استذكار تفاعلية (Smart Flashcards)**:
   - إنشاء بطاقات استذكار ثلاثية الأبعاد (3D Flip) بالعدد المطلوب، مقسمة حسب الصعوبة والنوع وتعمل بسلاسة في وضع عدم الاتصال.

6. **🎯 بنك أسئلة واختبارات تفاعلية (Custom Quizzes & Exams)**:
   - تدريب بنظام الخطوة بخطوة (Stepper) أو ورقة امتحان كاملة (Exam Sheet) مع تصحيح فوري ودرجات مئوية.
   - **خصوصية الامتحان**: تم إخفاء أرقام صفحات الأسئلة أثناء أداء الاختبار لضمان تجربة اختبار حقيقية ودون كشف الإجابات مسبقاً.

7. **📊 المخططات والمفاهيم المرئية مع الاستفسار التفاعلي (Diagrams with AI Q&A)**:
   - عرض تصاميم هندسية وتدفقات منطقية للمفاهيم الأساسية دون مربعات سوداء أو تشوهات.
   - **الاستفسار الذكي**: يستطيع المستخدم كتابة أي سؤال أو اختيار اقتراحات جاهزة للاستفسار عن أي شكل ومخطط، ليقوم الذكاء الاصطناعي بشرحه وتوضيح أبعاده وأمثلة عليه وكيف يرد في الامتحان.

8. **🌙 دعم كامل للوضع الليلي والنهاري (Dark & Light Mode)**:
   - تصميم واجهات عصري متناسق يتكيف بسلاسة مع تفضيل المستخدم في الإضاءة.

9. **📱 تصميم متجاوب 100% للهواتف والأجهزة اللوحية (Mobile & Tablet Responsive)**:
   - تناسق كامل على مختلف الشاشات، مع معالجة وضبط الأزرار لمنع أي تداخل مع نصوص المستندات في وضع التابلت.

10. **🎨 هوية وشعار عصري وأيقونة APK مخصصة**:
    - شعار متقن يدمج الكتاب العصري مع شبكة الذكاء الاصطناعي وشعلة المعرفة، مدمج بجميع المقاسات الرسمية في نظام Android لتجنب أي أيقونة رمادية افتراضية.

## 🛠️ البنية التقنية (Technology Stack)

- **Frontend**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + Lucide Icons.
- **Backend**: Node.js + Express API (`server.ts`).
- **AI Engine**: Google Gen AI SDK (`@google/genai`) مع استخدام نموذج `gemini-3.8-flash` فائق السرعة والموثوقية.
- **Document Parsers**: `pdf-parse` لفهرسة صفحات الـ PDF، و `mammoth` لملفات DOCX.
- **Mobile Container**: Android Native WebView + AndroidX WebKit (`WebViewAssetLoader`) لخدمة المحتوى المحلي بأمان وبسرعة فائقة.

## 🚀 دليل التشغيل المحلي (Development Quickstart)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20 أو أحدث).
- مفتاح API مجاني لـ Gemini من [Google AI Studio](https://aistudio.google.com/).

### 2. تثبيت الحزم وتشغيل التطبيق
```bash
# 1. الدخول إلى مجلد المشروع
cd studymind

# 2. تثبيت التبعيات البرمجية
npm install

# 3. إعداد متغير البيئة لمفتاح الذكاء الاصطناعي في ملف .env
echo "GEMINI_API_KEY=your_actual_gemini_api_key_here" > .env

# 4. تشغيل السيرفر التفاعلي الكامل
npm run dev
```

التطبيق سيعمل مباشرة على المتصفح:
👉 **`http://localhost:3000`**

## 📱 خطوات بناء وتحميل ملف Android APK جاهز بدون أخطاء

### لماذا ظهر خطأ "تعذر تحميل صفحة الويب" سابقاً وكيف تم حله نهائياً؟
- **السبب السابق**: كان ملف الـ APK موجهاً لعنوان محاكي تجريبي (`10.0.2.2:3000`) دون تضمين ملفات الويب داخل التطبيق نفسه، فعند تثبيته على هاتف حقيقي بحث عن السيرفر ولم يجده فظهرت الرسالة.
- **الحل الجذري الآن**: تم ربط بناء واجهة الويب مباشرة داخل حزمة الـ APK عبر أمر `npm run build:android`، وتحديث `MainActivity.java` لاستخدام `WebViewAssetLoader` الرسمي من AndroidX. ملفات التطبيق الآن مدمجة في مسار `android/app/src/main/assets/`، مما يجعل التطبيق يفتح فورياً وبشكل كامل بدون إنترنت!

---

### الطريقة الأولى: التحميل الجاهز عبر GitHub Actions (الأسهل 100% بدون أي تثبيت على جهازك)

1. ارفع المشروع إلى حسابك على **GitHub**:
   ```bash
   git add .
   git commit -m "Update StudyMind standalone APK with offline assets"
   git push origin main
   ```
2. في صفحة مستودعك على GitHub، اضغط على تبويب **Actions**.
3. ستجد سير العمل: **"Build StudyMind Android APK"** يعمل تلقائياً (يقوم ببناء حزمة الويب أولاً ثم تجميع ملف الـ APK).
4. بعد اكتمال البناء باللون الأخضر (يستغرق دقيقتين)، انزل لأسفل الصفحة في قسم **Artifacts**.
5. قم بتنزيل **`StudyMind-Debug-APK.zip`**، وفك الضغط لتحصل على ملف **`app-debug.apk`**.
6. ثبته على هاتفك، وسيفتح التطبيق فورياً ويعمل بسلاسة تامة!

---

### الطريقة الثانية: البناء محلياً على جهازك

إذا كان مثبت لديك **Java JDK 17** و **Android Studio / SDK**:

```bash
# 1. بناء حزمة الويب ونسخها تلقائياً إلى مجلد أصول أندرويد
npm run build:android

# 2. الانتقال إلى مجلد أندرويد وتجميع الـ APK
cd android
./gradlew assembleDebug
```

الملف النهائي الجاهز للتثبيت تجده في:
👉 `android/app/build/outputs/apk/debug/app-debug.apk`

## 🔒 الخصوصية والحفظ المحلي (Local Persistence & Privacy)

- يتم تخزين جميع المستندات والمحادثات والبطاقات والاختبارات في التخزين المحلي للهاتف (`localStorage` و `IndexedDB`)، وتبقى متاحة ومحفوظة حتى بعد إغلاق التطبيق أو إعادة تشغيل الهاتف أو انقطاع الإنترنت.
- لا توجد أي إعلانات أو نوافذ افتراضية مشوشة، والتطبيق مصمم بالكامل لتوفير تجربة استذكار أكاديمية احترافية وسلسة.
