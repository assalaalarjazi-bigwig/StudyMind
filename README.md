# StudyMind — منصة الاستذكار والتعلم التفاعلي الذكي
> **StudyMind — AI-Powered Interactive Learning Platform & Android APK**

تطبيق دراسي تفاعلي متكامل قائم على أحدث تقنيات الذكاء الاصطناعي من Google Gemini، يتيح للطلاب والمعلمين رفع الكتب والمذكرات الدراسية (PDF، DOCX، TXT) وتحويلها إلى مساحة تعلم تفاعلية تشمل: المحادثة المدعومة بالبراهين والمصادر، الملخصات الشاملة، بطاقات الاستذكار السريع، الامتحانات التفاعلية، ورسوم المخططات التوضيحية مع إمكانية استفسار الطالب وسؤاله عن أي شكل ومخطط لفهمه بشكل معمق.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **📚 معالجة المستندات الكبيرة بدقة عالية**:
   - قراءة واستخراج نصوص ملفات PDF و DOCX وحساب عدد الصفحات الفعلي بدقة كاملة.
2. **💬 محادثة معرفية موثقة (Grounded RAG Chat)**:
   - إجابات دقيقة مستندة حصراً إلى نصوص المستند مع توثيق أرقام الصفحات الحقيقية.
3. **📝 ملخصات مفاهيمية عميقة (In-Depth Summaries)**:
   - تلخيص شامل، تنفيذي، أو سريع للفصول، مع استخراج القواعد والمفاهيم والنقاط الحرجة للاختبارات.
4. **🗂️ بطاقات استذكار تفاعلية (Smart Flashcards)**:
   - إنشاء بطاقات استذكار ثلاثية الأبعاد (3D Flip) بالعدد المطلوب (حتى 60 بطاقة أو عدد مخصص)، مقسمة حسب الصعوبة والنوع.
5. **🎯 بنك أسئلة واختبارات تفاعلية (Custom Quizzes & Exams)**:
   - تدريب بنظام الخطوة بخطوة (Stepper) أو ورقة امتحان كاملة (Exam Sheet) مع تصحيح فوري ودرجات مئوية.
   - **خصوصية الامتحان**: تم إخفاء أرقام صفحات الأسئلة أثناء أداء الاختبار لضمان تجربة اختبار حقيقية ودون كشف الإجابات.
6. **📊 المخططات والمفاهيم المرئية مع الاستفسار التفاعلي (Diagrams with AI Q&A)**:
   - عرض تصاميم هندسية وتدفقات منطقية للمفاهيم الأساسية دون مربعات سوداء أو تشوهات.
   - **الاستفسار الذكي**: يستطيع المستخدم كتابة أي سؤال أو اختيار اقتراحات جاهزة للاستفسار عن أي شكل ومخطط، ليقوم الذكاء الاصطناعي بشرحه وتوضيح أبعاده وأمثلة عليه وكيف يرد في الامتحان.
7. **🌙 دعم كامل للوضع الليلي والنهاري (Dark & Light Mode)**:
   - تصميم واجهات عصري متناسق يتكيف بسلاسة مع تفضيل المستخدم في الإضاءة.
8. **📱 تصميم متجاوب 100% للهواتف الذكية (Mobile Responsive)**:
   - تناسق كامل على الشاشات الصغيرة، بدون أي إزاحة عرضية أو عناصر مقصوصة.
9. **🎨 هوية وشعار عصري وأيقونة APK مخصصة**:
   - شعار متقن يدمج الكتاب العصري مع شبكة الذكاء الاصطناعي وشعلة المعرفة.
   - تم تضمين الأيقونات بجميع المقاسات الرسمية لملف Android APK لمنع أي شاشة أو أيقونة افتراضية رمادية.

## 🛠️ البنية التقنية (Technology Stack)

- **Frontend**: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + Lucide Icons.
- **Backend**: Node.js + Express API (`server.ts`).
- **AI Engine**: Google Gen AI SDK (`@google/genai`) مع استخدام نموذج `gemini-3.8-flash` فائق السرعة والموثوقية، مع نظام إعادة محاولة ذكي (Exponential Fallback).
- **Document Parsers**: `pdf-parse` لفهرسة صفحات الـ PDF، و `mammoth` لملفات DOCX.
- **Mobile Packaging**: Android Studio / Gradle مشروع جاهز في مجلد `android/` و workflow عبر GitHub Actions.

## 🚀 دليل التشغيل المحلي خطوة بخطوة (Quickstart Guide)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- مفتاح API مجاني لـ Gemini من [Google AI Studio](https://aistudio.google.com/).

### 2. تثبيت الحزم وتشغيل التطبيق
```bash
# 1. الدخول إلى مجلد المشروع
cd studymind

# 2. تثبيت التبعيات البرمجية
npm install

# 3. إعداد متغير البيئة لمفتاح الذكاء الاصطناعي
# أنشئ ملف .env وضع فيه مفتاحك الخاص:
echo "GEMINI_API_KEY=your_actual_gemini_api_key_here" > .env

# 4. تشغيل السيرفر التفاعلي الكامل (Full-Stack Dev Server)
npm run dev
```

التطبيق سيعمل مباشرة على الرابط:
👉 **`http://localhost:3000`**

## 📱 خطوات بناء وتحميل ملف Android APK جاهز بدون أخطاء

هناك طريقتان سهلتان ومجربتان للحصول على ملف APK نهائي جاهز للتثبيت على هاتفك:

### الطريقة الأولى: التوليد التلقائي عبر GitHub Actions (الأسهل - بدون الحاجة لتثبيت أي برامج على جهازك)

1. ارفع المشروع إلى حسابك على **GitHub**:
   ```bash
   git add .
   git commit -m "Update StudyMind with mobile responsive design and APK icons"
   git push origin main
   ```
2. في صفحة مستودعك على GitHub، توجه إلى تبويب **Actions**.
3. ستجد سير العمل: **"Build StudyMind Android APK"** يبدأ تلقائياً.
4. بمجرد انتهاء البناء (يستغرق دقيقتين تقريباً)، انزل إلى أسفل الصفحة في قسم **Artifacts**.
5. حمل الملف المضغوط **`StudyMind-Debug-APK.zip`**، وفك الضغط لتحصل على ملف **`app-debug.apk`**.
6. انقله لهاتفك وثبته مباشرة!

---

### الطريقة الثانية: البناء محلياً على جهازك بواسطة Gradle

إذا كان لديك **Java JDK 17** و **Android SDK**:

```bash
# 1. بناء ملفات الواجهة للإنتاج
npm run build

# 2. الانتقال لمجلد أندرويد وبناء الـ APK
cd android
./gradlew assembleDebug
```

الملف الناتج سيكون موجوداً في المسار:
`android/app/build/outputs/apk/debug/app-debug.apk`
